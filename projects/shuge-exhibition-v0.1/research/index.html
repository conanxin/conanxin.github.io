设计说明

Workspace 是 P5-D Track C 引入的研究会话持久化机制。每个 workspace 绑定一个或多个 collection 集合，附带 question、status、search_plan、evidence_ledger、evidence_packs、citations、gaps、user_notes、review_status 等字段。

Workspace 的 run 命令幂等：已完成的 collection 会自动跳过，可使用 --force 重跑。

v0.1 仅展示 workspace 元数据，未实现 web 端创建/运行；这些操作通过 scripts/workspaces.py CLI 完成。
