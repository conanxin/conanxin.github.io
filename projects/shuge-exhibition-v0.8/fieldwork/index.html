Introduction · 为什么需要 Fieldwork?

数字展览通常止步于「文本证据 + 空间锚点」两层。然而许多关键问题需要现场才能回答:桑干河今天的实际走向与《水经注》记载是否吻合?紫禁城琉璃瓦的现行颜色与《工程做法》规定是否一致?临安 (杭州) 凤凰山脚下的南宋御街遗址,如何与《梦粱录》中的街市描述对应?

Fieldwork Bridge 不替代文本证据,也不替代空间锚点。它提供第三条证据来源:现场笔记、照片、GPS、访谈 — 全部与已有 citation_id 锁定,确保与 P5-D 终态数据可追溯。

v0.4 Status Note

重要边界

本期 仅交付 schema + 2 个 mock records。真实的实地照片、GPS 数据、田野笔记、访谈录音由 P5-E 接入。本期不抓取 shuge.org 任何资源,不引入 GIS,不存储实际照片(总容量限制 ≤8 GB,沿用 P5 阶段预算)。

所有 fieldwork 字段保持 placeholder 状态 (gps_lat/gps_lng 为示意坐标,raw_notes_path 为路径占位)。
