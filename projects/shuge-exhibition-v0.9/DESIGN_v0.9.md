## 0. 摘要

v0.9 把 v0.8 「Evidence-backed Research Publication」进一步升级为 **Public Research Portfolio**。新增三个并列的 schema 层:

1. **Public Article Pages** —— 每篇文章对外可见的最终呈现,8 段语义结构(title / abstract / methods / evidence / claims / citations / limitations / bibliography)。
2. **Peer Review Record Schema** —— article 的同行评审记录;review_id + comments + score + status。
3. **Research Portfolio** —— 长期研究档案,5 个聚合 section(projects / articles / exhibitions / methods / infrastructure)。

三个 schema 都建立在 v0.4 → v0.8 已冻结的 ID link 之上,**没有引入新数据源**,**没有改写任何 Citation ID**,**没有允许 auto-publish**。

## 2. Public Article Pages

### 2.1 schema 字段 (8 段语义结构)

| 字段 | 来源 | 边界 |
|---|---|---|
| `title_zh` / `title_en` | 继承 v0.8 article.title_* | 不改写、不翻译 |
| `abstract_zh` / `abstract_en` | 派生自 v0.7 draft + v0.8 article sections | ≤ 200 字符,**LLM 不会自动扩写** |
| `methods_zh` / `methods_en` | 派生自 v0.7 outline + v0.8 article sections | 不引入新方法 |
| `evidence_summary_*` | 聚合 v0.7 evidence_paragraphs + evidence_cards | 不读 full_text |
| `claims_summary_*` | 聚合 v0.7 evidence_paragraphs.claims | claim_id 原样保留 |
| `citations_summary_*` | 聚合 v0.7 evidence_paragraphs.citation_ids | SHUGE:p<post_id>:<page_seq> 原样保留 |
| `limitations_zh` / `limitations_en` | 聚合 v0.6/v0.7/v0.8 gaps | gap_id 原样保留 |
| `bibliography_section` | 引用 bibliography.works / institutions / citations | full_text_unavailable=true |

### 2.2 实际页面

- `/articles/<id>/index.html` —— 3 篇文章的独立公共页
- 模板可复用,通过 issue_id (papa-*) 选择具体内容

### 2.3 边界

- **review_status=DRAFT / REVIEW / REVISED 三态,PUBLISHED 严格禁止**。
- 即使 review_status=REVISED,**v0.9 也禁止自动进入 PUBLISHED**。
- public page 不是 review 记录库,只是 article 的对外呈现视图。

## 3. Peer Review Record Schema

### 3.1 schema 字段

| 字段 | 说明 |
|---|---|
| `review_id` (rev-*) | local-only ID |
| `article_id` (article-*) | 引用 v0.8 article |
| `draft_id` (draft-*) | 引用 v0.7 draft |
| `reviewer_id` (revr-*) | placeholder,**不是真实人物** |
| `round` | 评审轮次 |
| `rubric_dimensions_reviewed` | 引用 v0.8 publication_workflow.rubric_dimensions |
| `comments[]` | 每条 comment 包含 rubric_dimension / score / weight / comment_zh / evidence_links_checked / linked_paragraph_ids / blocker |
| `overall_score` | 静态演示值,**非自动评分** |
| `score_band` | BLOCKED / NEEDS_REVISION / ACCEPTABLE / STRONG / EXEMPLARY |
| `review_status` | PENDING / APPROVED / NEEDS_REVISION / REJECTED |
| `decision` | APPROVE_TRANSITION / BLOCK_TRANSITION |
| `next_state_recommendation` | DRAFT / REVIEW / REVISED,**PUBLISHED 禁止** |

### 3.2 边界

- **不调动真实人类评审员** —— reviewer_id 是 placeholder。
- **不自动评分** —— score 是静态 demo。
- **不自动 BLOCK / APPROVE** —— decision 是 schema 描述。
- **不自动进入 PUBLISHED** —— v0.9 边界禁止。
