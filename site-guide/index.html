显示无障碍设计目标与已落实项

无障碍是本站设计的持续目标, 并非已通过完整第三方审计的合规声明。已落实的具体实践包括:

  • 所有可交互元素 (链接、按钮、可折叠控件) 在 :focus-visible 状态下显示 2px solid var(--site-accent) 焦点轮廓, 配合 outline-offset: 4px, 对应 WCAG 2.4.7 的可见焦点要求。
  • 链接默认具备可读的 :hover 与 :focus 状态, 颜色对比满足正文 ≥ 4.5:1 (WCAG 1.4.3)。
  • 图像 <img> 在源代码中需要 alt 属性; 当前 assets/site/design.css 提供 .visually-hidden 工具类供装饰性背景图像使用。
  • 页面结构遵循 <main> + <article> / <section> 的语义层级, 便于屏幕阅读器导航。

本节内容为设计目标与已落实项, 不是已通过 WCAG 2.1 AA 第三方合规审计的认证声明。需要完整无障碍评估 (含辅助技术实测) 时, 应另行委托独立审计。
