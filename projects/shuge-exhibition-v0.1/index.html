展厅章节

1 · 语料库 (Corpus)

三部 JDA 核心古籍：水经注（956 页 / 322,030 字）、工程做法（1,456 页 / 277,723 字）、河防一览（122 页 / 29,278 字）。所有页面已完成 OCR 并进入 FTS5 索引；总计 3,553 页可搜索文本。辅以天工开物、园冶、梦粱录等周边古籍。

2 · 专题集合 (Collections)

两个策展性研究集合：historical-hydrology（历史水利与河防）与 architecture-construction（建筑营造与工程做法）。每个集合含 WORK 种子 + 自动扩展的 PAGE 成员，共 2,224 条 memberships。

3 · 引文证据 (Evidence)

234 个研究问答（65 BRIEF_READY + 60 INSUFFICIENT_EVIDENCE + 109 SEARCHING），378 条 claim 全部带 Citation ID 引用，无 0 unsupported sentence。证据在合成前过滤出 out-of-collection 文档。→ 进入引文检索

4 · 研究工作区 (Workspace)

3 个跨集合研究工作区（水经注河水分布研究、工程做法柱径标准、营造与水利交叉），状态 OPEN。20 个 P5-D QA queries 全部入库（12 个 negative controls 全部 abstained correctly）。→ 进入工作区

精选作品

以下九部作品按 JDA 核心 · 证据页 · 主题亮点三类编排。专题展柜另见。

项目说明

本项目从 shuge.org 的开放古籍目录出发，经 P1–P5-A 完成语料消化、P5-B2 完成 JDA 核心冻结、P5-C 完成专题集合、P5-D 完成集合治理 + 检索精度 + 工作区。每阶段均以 GitHub Issue 为唯一任务书与 acceptance gate。

核心准则

0 个 unsupported claims · 0 个 out-of-collection leakage · 2 个 verified-false 命中但全部 out-of-collection · Citation ID 与 provenance 自 P5-B2 起保持不变。
