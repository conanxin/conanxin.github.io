# P10 — Yarvin 阅读连续性与键盘焦点

日期：2026-10-22。设计基线：SITE_DESIGN.md v1.9.1；P9 主分支。

## 问题
P9 已补齐完整 21 项内容导航，但内链跳转只改变 hash/滚动位置；对使用键盘或辅助技术的读者，浏览焦点可能仍留在目录按钮或搜索结果。再次进入页面也没有明确的“继续上次阅读”入口。

## P10 最小实现
- 增加内链及首次深链接的焦点转移：章节 h2 或模块 h2 临时设为 tabindex=-1，调用 focus({preventScroll:true})，保留浏览器的原生 hash 与滚动历史。
- 点击同一个 hash 链接时也可重新聚焦，不依赖 hashchange 必然触发。
- 在本地浏览器记录最后实际滚动到的章节/模块 ID；首屏提供显式“继续上次阅读”链接，仅在保存的 ID 有效且不是第一章时显示。**不自动跳转**，带 hash 的外部深链接继续优先。
- 内容聚焦轮廓采用全站 --site-accent；无第二套配色；CSS/JS 缓存版本提升到 20261022-p10。
- 新增单元测试和 Chromium 深链接/恢复测试；不改文章正文、P4–P7 JSON 或全站 CSS。

## 验收与边界
PR 的测试和截图通过后合并；合并后必须单独验证 Pages 生产 HTTP 与静态资源。localStorage 记录的是本页最后章节 ID，不是原文、个人身份或云端同步。清理站点存储会清除该进度。
