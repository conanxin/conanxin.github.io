摘要

本文以日本內閣文庫藏明吳琯校《水經注》卷之十一（Cabinet Library / 国立公文書館，漢二三五五 / 函二九一 / 冊一四（5））底本影像為核心證據，整合 R4（地理空間基線）/ R4.1（學術審計）/ R4.2（外部核驗）/ R4.3（文本證據比對）/ R4.3A（統計勘誤與影像複核）共五層研究成果，系統討論《水經注》卷十一易水章中范陽、容城與故安三個城邑的空間關係、易京的相對方位、以及兩項漢代封侯事件的版本異文。

研究確認三項基本事實：（一）易水出涿郡故安縣閻鄉西山，東過范陽縣南，又東過容城縣南；（二）「易水又東逕易京南」句法上表達的是易水流經易京南側，與 Cabinet Library 影像跨句一致的「易京城在易城西四五里」共同指向易京位於易水之北，而非之南；（三）容城段的漢代封侯事件應與范陽段分開記錄，不可將容城段紀年誤歸於范陽，亦不可將王莽更名「深澤」誤認為受封地點。

研究同時記錄四組尚待獨立確認的版本異文：範陽封侯時間（中二年/中元三年）、範陽受封降王姓名（代/信）、趙將姓名（夜/夕/某）、容城受封降王姓名（唯徐盧/攜徐盧/撅徐盧），以及一項獨立研究線索——《水經注疏》記載趙將夜受封於「高帝八年」而非「六年」——均列為 尚待獨立確認的歷史事實，本文不作最終裁決。

二、易水的文本空間敘述

2.1 易水起源：pid1655 正文首段

Cabinet Library 底本 pid1655 正文首行大字記載易水的起源：

「易水出涿郡故安縣閻鄉西山」

[古籍直接記載] [CITE-7]。此句由三個地理節點構成：涿郡（郡級行政區）、故安縣（易水所出之縣）、閻鄉西山（易水所出之山）。三個節點構成自上而下的空間縮放：郡—縣—鄉—山。維基文庫整理版作「閻鄕」（異體字「鄉」），Wikisource 四部叢刊本與 Cabinet Library 底本皆作「閻鄉」（正體字）[版本校勘結果] [CITE-8]。此處「鄕/鄉」為同字異寫，不構成實質異文。

2.2 範陽—容城段：pid1657 大字雙行標題

Cabinet Library 底本 pid1657 大字雙行標題記載易水東流過程中的兩個關鍵城邑：

「東過范陽縣南，又東過容城縣南」

[古籍直接記載] [CITE-9]。此句由「東過…縣南」動詞結構串聯兩個城邑，揭示三層空間信息：（一）方位（文本河流路線敘述）：《水經注》以「東過范陽縣南，又東過容城縣南」描述易水流經兩縣的南側，句法「X 水逕 Y 南」表達「水流經過城邑的南側外側」；這是文本中的河流路線敘述，不能據此推出兩縣全部地域的絕對方位，亦不能直接映射為現代地理方位。本文保留「南易水／北易水」不同水系的辨析空間（南北易水屬獨立研究問題）；（二）序列：範陽在西、容城在東（「又東過」表達易水自西向東的流路）；（三）語法：「南」字標誌易水與城邑的相對位置，而非城邑的絕對方位[研究者文本推論]。 R4.4B 修訂：原 R4.4 §2.2 「兩個城邑皆位於易水之南側」表述可能誤讀為「兩城位於河之南」。R4.4B 統一改為「《水經注》描述易水流經兩縣的南側」並明示這是文本中的河流路線敘述，不能直接映射為現代地理方位。

識典古籍《山水二經合刻》同句作「容城」[CITE-4]；《山水二經合刻》本另有一句作「容成」（「成」字），R4.3A 標記為「容城/容成」一字之差，但 Cabinet Library 底本影像作「容城」（清晰可辨，「城」字左半土字旁完整）[版本校勘結果] [CITE-10]。本文判讀採「容城」為正。

2.3 大利亭與巨馬水：pid1659 互攝通稱段

Cabinet Library 底本 pid1659 記載容城段的水系互攝現象：

「南流於容城縣西北大利亭東南合易水而注巨馬水也……是則易水與諸水互攝通稱」

[古籍直接記載] [CITE-11]。此句包含三個關鍵地理術語：（一）大利亭：容城縣西北的一個聚落節點，作為水系匯流的地理標誌；（二）合易水而注巨馬水：故安水（自容城西北）東南匯入易水，再向東注入巨馬水；（三）互攝通稱：易水、故安水、巨馬水、濡水、淶水於涿郡範陽縣一帶會流，各水名稱在不同語境下可互換使用[研究者文本推論]。R4-YSH-007（大利亭節點）與 R4-YSH-006（互攝通稱水系關係）對應此段文本，兩條均歸入 PARTIALLY_SUPPORTED，等級提升需外部水文地理佐證。

四、易京、武陽與大利亭的歷史敘述

4.1 易京方位：Claim 011 方向性誤讀的修正

Cabinet Library 底本 pid1661 記載易京的相對方位：

「易水又東逕易京南……謂之易京城，在易城西四五里」

[古籍直接記載] [CITE-13]。R4.1 曾將「易水又東逕易京南」解讀為「易京城位於易水之南」，並以此推論「範陽以東、容城以西」的空間位置。R4.3 + R4.3A 重新檢視後確認此句法應解讀為：易水從易京的南側流過（即易京在易水之北），而非易京在水之南。Cabinet Library 影像同段「易京城在易城西四五里」跨句一致支持「易京在易水之北」的判讀（易城亦在易水之北）[研究者文本推論] [CITE-14]。

R4.4 聲明：本文不採用「易京城位於易水之南」之表述。R4.1 的 PARTIALLY_SUPPORTED 結論「易京城位於易水之南、範陽以東、容城以西」中，第一部分（南/北方位）為方向性誤讀，第二部分（範陽以東、容城以西）為基於 pid1657 大字標題序列的推論。本文採 R4.3A 修正方向（北），並標記 R4-YSH-011 為方向修正後的 PARTIALLY_SUPPORTED。REAL_WORLD_LOCATION（現代地理事實）仍為 尚待獨立確認的歷史事實——古籍文本記載不可直接等同於考古地理事實。

需注意：本文使用「在易水之北」是基於文本內部句法推論，並非指現代河北易縣一帶考古地理意義上的具體經緯度。易京（公孫瓚遷都處）的考古定位屬另一獨立研究問題，本文不涉入[尚待獨立確認的歷史事實]。

4.2 武陽與燕下都

七、研究結論

綜合 R4 / R4.1 / R4.2 / R4.3 / R4.3A 五層研究成果，本文得出以下七項結論：

  1. 空間序列結論（SUPPORTED，R4.4B 限定）：易水出涿郡故安縣閻鄉西山，東過范陽縣南，又東過容城縣南——三個城邑在文本空間中由西向東排列；《水經注》以「東過范陽縣南，又東過容城縣南」描述易水流經兩縣的南側（pid1655 + pid1657）。這是文本中的河流路線敘述，不能直接映射為現代地理方位；亦不據此推出兩縣全部地域的絕對方位[古籍直接記載] + [研究者文本推論]。 R4.4B 限定：原 R4.4 結論 #2 末段「皆位於易水之南側」被部分讀者誤讀為「兩城邑絕對位於易水南側」；R4.4B 統一改為「《水經注》描述易水流經兩縣的南側」並明示不能直接映射為現代地理。
  2. 易京方位結論（Claim 011 方向修正後 PARTIALLY_SUPPORTED，R4.4B 限定）：「易水又東逕易京南」句法上表達易水從易京南側流過（pid1661 + R4.3A overlay）。「易京城在易城西四五里」是另一組東西方位關係（=易京在易城之西四五里），不能單憑這組東西方位關係獨立證明易京位於易水北側；南北方位主要依據「X 水逕 Y 南」句法推論「Y 在 X 水之北」[研究者文本推論]。 R4.4B 限定：原 R4.4 結論 #2 「跨句一致指向...（易城亦在易水之北）」將東西方位關係誤用作南北方位的獨立證據；R4.4B 改為「東西方位關係不可單獨證明易京位於易水北側」，南北方位結論僅依據「X 水逕 Y 南」句法。
  3. 範陽—容城—三事件分離結論（R4.4A 升級為 SUPPORTED）：Cabinet Library pid1661 容城段文字記錄三項獨立歷史事件，須分開記錄：(a) 漢高帝六年（或八年）封趙將夜/夕於【深澤】（高帝事件，受封地 = 深澤侯國）；(b) 漢景帝中三/中元三年以匈奴降王唯徐盧/攜徐盧於【容城】（景帝事件，受封地 = 容城侯國）；(c) 王莽將容城改名為【深澤】（王莽改名事件）。不得將容城段紀年誤歸於範陽，亦不得將高帝事件受封地「深澤」與景帝事件受封地「容城」混為一談（R4.4A 勘誤 A1 撒銷重寫 + A2 重寫 + V05 新增）[研究者文本推論]。
