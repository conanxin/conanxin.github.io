字体与层级

全站使用 :root 中的 --site-serif 与 --site-sans, 标题使用衬线字体, 正文与 UI 使用无衬线字体。

正文与段落

正文段落采用 16px / 行高 1.95 的 --site-sans。长文段落(.post-content)使用 17px 衬线、行高 1.95。

需要强调关键概念时, 可使用 粗体 或 斜体; 行内代码用 code 标签。

折叠内容

显示技术细节

全站主题: unified-v1。所有页面经 scripts/build_site.py transform() 注入 body.site-unified 与 data-site-theme 属性。

<body class="site-unified" data-site-theme="unified-v1" data-site-kind="content">
显示无障碍声明

本站遵循 WCAG 2.1 AA 标准。所有交互元素具备 :focus-visible 焦点轮廓, 链接具备 :hover 状态, 图像具备 alt 属性。
